# Pesquisa de Oportunidade Controle Multi

ONE PAGE responsiva em HTML, CSS e JavaScript para registrar o diagnóstico dos GNs.

## Publicar na Vercel

1. Importe este repositório na Vercel.
2. Mantenha Framework Preset como Other.
3. Não é necessário informar comando de build.
4. Publique o projeto.

## Conectar ao Supabase

1. Crie um projeto no Supabase.
2. Abra o SQL Editor e execute o arquivo supabase.sql.
3. Em Project Settings > API, copie a Project URL e a chave pública anon.
4. Preencha os dois valores no arquivo config.js.
5. Nunca use a chave service_role no navegador.

Enquanto o Supabase não estiver configurado, o formulário funciona em modo de demonstração e salva as respostas apenas no navegador do dispositivo.
